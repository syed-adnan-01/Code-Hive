# Project Instructions & UI Guidelines

## UI Principles
- **Do NOT add demo or status badges**: No "Firebase Auth Live", "Demo Mode", or promotional status badges in the navbar or layout.
- **Do NOT add dummy snippet or template buttons**: No "Hello World", "Stdin Example", or boilerplate reset buttons in toolbars.
- **Do NOT add test tabs or debug drawers**: No "Backend API Test", dummy server testing tabs, or language templates side drawers. Test logic in backend test scripts instead.
- **Production-grade cleanliness**: Only add features and UI controls requested by the user. Keep layouts sleek, clean, and free of placeholder noise.
